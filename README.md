# JobTrack JS

JobTrack is a simple job application tracking web application that helps users manage and track their job applications, interviews and offers in one place.

## Live Demo

[View JobTrack JS](https://veera-kumar-4856.github.io/JobTrack-JS/)

## Features

- Add job applications
- Edit existing applications
- Delete applications
- Track application status
- Search applications by company or role
- Filter applications by status
- View dashboard statistics
- Add job application notes
- Open job postings using job URLs
- Store application data using LocalStorage
- Responsive design for desktop, tablet and mobile
- Persistent data after page refresh

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub

## Application Status

Job applications can be tracked using the following statuses:

- Applied
- Interview
- Offer
- Rejected
